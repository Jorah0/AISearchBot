# Pass 59: Model lab (local AI model marketplace, designer, learning, training, broker, media)

Source: `Local_AI_Marketplace_Handbook.pdf` (Nov 2026, 53 pp.), supplied by the owner. Owner choices (2026-11-24):
full handbook including scratch training; catalog, designer, evidence broker and media runtimes all in scope.

## Goal
One **Model lab** tab where the owner picks or designs the local model Lodestar uses, sees whether it fits *this*
computer (GPU / RAM / disk, with a reserve such as "OBS live"), teaches it from their own decisions with the premium
AIs (Claude, OpenAI, ...) as teachers, trains it (LoRA adapter on a checkpoint, or a model from scratch) in a separate
training environment, and promotes a candidate only when it measurably beats the live one, with rollback.

## Principles (from the handbook, mapped to Lodestar rules)
- Estimates are labelled estimates; only a run on this machine is "measured". Unknown is shown as unknown.
- A selection is a versioned record; editing forks a revision; a running job keeps its pinned revision.
- Draft selection, candidate build and active release are separate. A failed candidate leaves the active one live.
- Nothing downloads weights or calls a paid AI without a click (or the owner's explicit auto pref). Full AI
  (`config.full_ai_check`) refuses training, release changes, installs and media jobs.
- Model training data never contains the salary floor, private answers, EEO answers, readiness, codes or secrets:
  examples are built from `jobmodel.decisions()` text (employer-safe) and teacher verdicts; the dataset builder
  runs `drafts.leaks` and drops any row that trips it.
- Training runs in its own environment (`HOME/train-env`, created on the owner's click) as a subprocess through
  `updater._proc` / `util.NO_WINDOW`; the app process never imports torch.
- Network: catalog sync from Hugging Face only on click (`util.fetch`, public metadata API, no weights);
  local services (Ollama, ComfyUI, LocalAI) only on loopback through a urllib helper like `jobmodel._post`.

## Modules (each owns its tables; created lazily with `CREATE TABLE IF NOT EXISTS` in an `_init()`)

### A. `lodestar/hwprofile.py` (hardware)
- `probe() -> dict`: `{at, gpus:[{index,name,total_gib,free_gib,used_gib,driver}], ram:{total_gib,free_gib},
  disk:{path,free_gib}, ollama:{running:[{name,size_vram_gib,context}]}, source:"nvidia-smi"|"none", error}`.
  nvidia-smi via `updater._proc` (`--query-gpu=index,name,memory.total,memory.free,memory.used,driver_version
  --format=csv,noheader,nounits`, MiB -> GiB); RAM via ctypes `GlobalMemoryStatusEx` (Windows) or `/proc/meminfo`;
  disk via `shutil.disk_usage(HOME)`; Ollama `/api/ps`. Never raises: missing parts are None + `error`.
- Profiles: meta `lab:profiles` = `{name: {reserve_gib, note}}`, defaults `Idle` 0, `OBS live` 3. Active profile in
  meta `lab:profile`. `budget(snapshot, profile) -> {per_gpu:[{index, effective_gib}], total_gib}`:
  effective = max(0, free - reserve). Manual snapshot override allowed (`manual=True` flag shown as such).

### B. `lodestar/modelcat.py` (catalog, estimate, fit, search, score)
- Variant record: `{id, family, name, source: ollama|curated|hf|private, publisher, revision, digest, task,
  inputs:[...], outputs:[...], specialization, params_b, quant, size_gib, context_max, arch:{layers, kv_heads,
  head_dim, hidden}, license, installed, notes, provenance:{field: publisher|local|estimated|unknown}}`.
- Sources: Ollama `/api/tags` + `/api/show` (model_info `*.block_count`, `*.attention.head_count_kv`,
  `*.attention.head_count`, `*.embedding_length`, `*.context_length`, details quantization/parameter_size);
  curated `lodestar/data/model_catalog.json` (hand-checked entries incl. image/speech/music/3D runtimes' models,
  each with `verified` date); private (lab-built candidates); HF on click (`/api/models?search=` metadata only,
  stored in table `catalog_hf`).
- `estimate(variant, workload) -> {lo_gib, hi_gib, parts:{weights, kv, workspace}, confidence, basis}` with workload
  `{operation: run|adapter_train|full_train|export, context, concurrency, kv_bytes (2 f16 | 1 q8 | 0.5 q4),
  placement: gpu|mixed|cpu}`. KV = 2 x layers x kv_heads x head_dim x kv_bytes x context x concurrency.
  Weights = size_gib (installed) or params_b x bytes-per-quant. Workspace = 0.5-1.5 GiB + 5-15% margin (range).
  Training: weights + LoRA (adapter) or weights+grads+AdamW (16 B/param fp32-master) + activations estimate.
  Missing arch -> confidence "unknown" (no fabricated range).
- `fit(est, budget, total_gib) -> {status: fits|borderline|incompatible|unknown, pct_lo, pct_hi, headroom_lo,
  headroom_hi, reasons:[...]}`: upper bound <= budget fits; lower > budget incompatible; else borderline.
  Handbook regression fixture: total 24, free 18, reserve 3 -> budget 15; 8-10 -> 33-42%, fits, 5-7 left;
  14-17 borderline; 26-30 -> 108-125%, short 11-15.
- `search(q, filters, profile) -> {items, counts, sources}`: exact id/name first, then token match on
  name/aliases/publisher/specialization/task/tags (+ simple typo tolerance via difflib), filters view=all|fits|installed,
  task, input, output, quant, source. "describes images" (input image) vs "generates images" (output image) synonyms.
  All entries stay visible by default; incompatible ones open.
- `score(cands, weights, bounds) -> ranked` (appropriateness): benefit clamp((v-floor)/(target-floor)), cost
  clamp((ceiling-v)/(ceiling-target)), weights sum to 1, reject equal/reversed bounds; unmeasured -> no number.
  Fixture: weights .5/.3/.2, F1 .70-.90, support .90-1.00, latency 1.2/2.8 -> (0.84,0.96,1.2)=73, (0.88,0.98,2.8)=69.

### C. `lodestar/modellab.py` (selection, preflight, releases) - integration owner
- Table `lab_selections(id, rev, mode existing|scratch, spec JSON, status, created_at, note)`; a save with
  `expected_rev` != current -> refused (revision guard); editing creates rev+1.
- Existing spec: `{variant_id, digest, num_ctx, concurrency, kv_type, profile, route: inference|adapter|full}`.
  Scratch spec: `{arch: llama, vocab, layers, hidden, mlp, heads, kv_heads, head_dim, context, tied, seed,
  tokenizer: new|<ref>, corpus, tokens_budget}`.
- `preflight(sel) -> gates [{gate, status pass|fail|unmeasured|inapplicable, detail, remedy}]`: fit, context,
  runtime (Ollama has it / exporter), data (eligible example count), training env ready, budget.
- Releases: meta `lab:release` `{active:{tag, digest, sel_id, rev, at}, previous:[...], candidates:[...]}`.
  `promote(tag)` only when its evaluation beats active (or no active) and gates pass; `rollback()`.
  `jobmodel` builds candidates as `lodestar-jobs:cand-<n>` with the selection's num_ctx/params; `ai.model_for`
  keeps returning the active release tag (`lodestar-jobs` stays the alias of the active one).

### D. `lodestar/teacher.py` (premium AIs teach the local model)
- Table `lab_examples(id, source decision|correction|teacher, decision_id, prompt, target JSON, status
  proposed|accepted|rejected, teacher_model, created_at, reviewed_at, split train|dev|test)`.
- `propose(n)`: for decisions without an example, ask the premium AI (primary non-Ollama, `ai.ask_json`, one batched
  call, fenced job text) for `{score 0-100, verdict pursue|pass, reasons}`; proposed rows wait for the owner's
  accept/edit/reject (Model lab > Learning). Ground truth = the owner's actual decision; a teacher verdict that
  contradicts it is flagged, never accepted silently.
- Splits by hash of the decision id (deterministic, group-stable): 70/15/15. Test split is frozen once used.
- `dataset(kind sft) -> path, sha` JSONL in `HOME/lab/datasets/`, accepted train rows only, each through
  `drafts.leaks`; same inputs -> same hash.
- Feeds `jobmodel.messages()` (accepted examples as few-shot) and the training worker (SFT JSONL).

### E. `lodestar/labtrain.py` + `lodestar/labtrain_worker.py` (training environment and worker)
- `env_status()`, `setup_env()` (click): create `HOME/train-env` venv, pip install pinned `torch` (CUDA wheel index),
  `transformers`, `peft`, `trl`, `datasets`, `accelerate`, `bitsandbytes` (Windows build), `safetensors`; logs to
  `HOME/logs/train-env.log`; Full AI refused.
- `scratch_params(spec) -> {total, breakdown}` pure Python: Vd + L(2d^2 + 2dk + 3dm + 2d) + d (+Vd untied);
  must give 26,354,176 for the handbook preset; `validate_scratch(spec) -> [errors]` (head divisibility, even
  rotary dim, vocab match, positive sizes).
- `plan(sel) -> job` (immutable: selection id+rev, dataset sha, hyperparameters); jobs table `lab_jobs(id, sel_id,
  rev, kind lora|scratch|export, status, plan JSON, progress JSON, log path, started, finished, idem_key UNIQUE)`.
- `start(job)` spawns `train-env/python labtrain_worker.py <job.json>` hidden; one GPU lease (meta `lab:lease`);
  pause file; worker writes progress JSON lines; stop on non-finite loss / budget.
- Worker (runs only inside train-env): `lora` (QLoRA SFT via TRL on a pinned HF base + dataset JSONL), `scratch`
  (LlamaForCausalLM(config), seed, param count assert, init hash, causal-LM pretraining on corpus, checkpoints
  at step boundaries, resume), `export` (merge adapter, llama.cpp `convert_hf_to_gguf.py` if configured,
  `llama-quantize`, write Modelfile, `ollama create <tag>`). The worker never sees API keys.

### F. `lodestar/broker.py` (evidence broker)
- `lodestar/data/evidence_event.schema.json` (EvidenceEvent v1, JSON Schema 2020-12): schema_version, event_id, op
  upsert|retract, workspace_id, evidence_id, revision, provider_id, source_id, occurred_at, policy_id.
- Tables: `ev_policy(policy_id, version, provider, flags JSON {discover,store,display,derive,embed,retrieve,train},
  expiry, retention)`, `evidence(workspace, evidence_id, revision, state current|superseded|retracted, provider_id,
  source_id, body JSON, observed_at, policy_id, PRIMARY KEY(workspace, evidence_id, revision))`,
  `ev_outbox(event_id PK, event JSON, delivered)`, `ev_receipts(consumer, event_id, PRIMARY KEY(consumer, event_id))`.
- `upsert(...)`/`retract(...)`: next revision in one transaction with the outbox row; an old upsert after a retract
  cannot revive it; duplicate event ids ignored.
- `resolve(workspace, evidence_id, purpose) -> {status ok|superseded|denied|gone, ...}`: purpose must be allowed by
  the policy (`train` needed for dataset export, `retrieve` for prompts).
- `consume(consumer, handler)`: idempotent by receipt. Adapters: `owner` (your profile facts / job postings Lodestar
  already stores, policy retrieve+train), `fixture`. `validate_event(e)` against the schema (hand-rolled checks, no
  jsonschema dependency).
- Teacher/dataset read evidence through `resolve(..., "train")`; a retracted record drops out of the next dataset
  and marks dependent examples stale.

### G. `lodestar/media.py` (local generation runtimes)
- Registry `lodestar/data/media_runtimes.json`: ComfyUI (127.0.0.1:8188, `/system_stats`, `/prompt`, `/history`),
  LocalAI (127.0.0.1:8080, `/readyz`, `/v1/models`), Ollama image (probe only), with operations
  (text->image, text->speech, text->music, image->mesh), reported VRAM where published (Hunyuan3D 10/21/29 GB).
- `probe()` loopback only; `submit(runtime, recipe)` on click; artifacts saved under `HOME/media/<job>/`; never sent
  anywhere. Fit uses modelcat estimate with the runtime's reported figure labelled "publisher-reported".
