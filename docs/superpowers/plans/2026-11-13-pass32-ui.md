# Pass 32: UI Overhaul Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Make Lodestar as easy to navigate and understand as the best tools in its class (Teal, Huntr, Linear-style
navigation): a Today home, a grouped seven-section sidebar, light + dark themes with clear hierarchy and focus, a
job drawer with a sticky header and section index, keyboard go-to keys, and apply-agent controls in the page.

**Architecture:** Same vanilla page (index.html / app.js / app.css). The E2E selector contract in
`docs/superpowers/specs/2026-11-13-ui-research.md` is kept: every `nav button[data-tab]` stays (grouped under section
headings, labels unchanged), every `section#id`, drawer group id and button name stays. New UI gets its own E2E test.

**Spec:** blueprint v1.1 section 18 (navigation, Career Discovery workspace, job card, approval center, accessibility)
+ `docs/superpowers/specs/2026-11-13-ui-research.md` (IA, Today spec, drawer, visual principles, priorities).

## Global Constraints
- Restart the server after static edits (web.ASSETS). E2E from PowerShell only. `overflow()` stays empty at 420px.
- No new dependency or CDN: icons are inline SVG; fonts are the system UI stack.
- Status is never colour-only (blueprint 18.5); every control keeps a visible `:focus-visible` ring; AA contrast in
  both themes.
- Renaming a button or tab label is a contract change: only with its tests in the same commit.

## Review Focus
1. A first-run user with no key, no jobs and no profile lands on Today and sees what to do first (no blank page).
2. Keyboard-only: every new control reachable, go-to keys never fire while typing in an input.
3. Light theme: chips, status pills and fit bands stay readable (not colour-only).
4. 420px width: the grouped sidebar and the Today page do not scroll sideways.
