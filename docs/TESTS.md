# Test matrix

One row per feature, with the unit/integration tests and the browser (E2E) tests that cover it, by exact name
(`module.Class.test_name`). Rows start from the full feature overview of 2026-11-07 (IDs kept, so each row traces back
to it) plus everything added since (pass 16.2 connections, the E2E suite). Features that are only planned are listed
at the end, without tests, until they exist.

- **Unit / integration**: `.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"`
- **E2E** (Playwright, installed Edge): `.venv\Scripts\python.exe -m unittest discover -s tests/e2e -p "e2e_*.py"`
  (needs `pip install -e .[e2e]`; skips cleanly without Playwright)
- **Guard**: `tests/test_feature_matrix.py` fails when a row lists no test, names a test that does not exist, puts a
  browser test in the unit column, or repeats an ID; when a test is named in no row; and when a row or a Planned ID
  disappears (the IDs are pinned in the guard). It parses the test files, so it runs without Playwright.
- **Convention**: every new feature adds a row here, a unit test, and an E2E test when it has UI.
